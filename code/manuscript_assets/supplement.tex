\section{Complete rejection-capable algorithm}

Let $A(t)$ be a target action available at selected task values and let
$\BF_r(t)$ be a sum of $r$ butterfly products.  The implementation executes
the following fixed protocol.  Training and certification random-number
generators are initialized from separate seeds; no certification vector
appears in optimization.

The fixed protocol is:
\begin{enumerate}
\item Fix five optimization seeds, candidate grid $\{1,2,4\}$, five certified
tasks, $\tau=0.15$, global $\delta=0.05$, and 2,048 probes.  The complete
family has $J=75$ hypotheses.
\item Fit all candidates with 1,500 minibatches of 48 action pairs and learning
rate 0.006; freeze each model before certification.
\item At every task, draw the registered Gaussian block and evaluate residual
and target actions.  Use $t=\log(2J/\delta)$ in the simultaneous certificate
from the main manuscript.
\item For each seed, accept the first candidate whose maximum five-task upper
bound is at most 0.15.  If none passes, return rejection.  Entry-built controls
and the apply/adjoint structural diagnostic cannot change this decision.
\end{enumerate}

For one product at dimension $n=2^L$, the forward recurrence stores the
stage inputs
\[
  z_{\ell+1}=F_\ell(t)z_\ell,\qquad \ell=0,\ldots,L-1.
\]
Given residual $e=z_L-y$, the reverse recurrence
\[
  a_L=e,\qquad a_\ell=F_\ell(t)^\mathsf{T}a_{\ell+1}
\]
gives the gradient of every active $2\times2$ core as the corresponding
outer product of entries of $a_{\ell+1}$ and $z_\ell$.  The implementation
performs these indexed core products directly and never differentiates an
assembled dense target.  For one right-hand side, forward application,
adjoint application, and a gradient step each use $O(rn\log n)$ arithmetic.
The untied factors store $O(rn\log n)$ scalars; the released reverse pass also
caches $O(rn\log n)$ activation scalars.  A streaming action alone needs only
$O(n)$ working storage beyond the factors.

\section{Frozen source and split}

The primary experiment contains 48 EarthScope requests: three stations times
four earthquakes times one event and one quiet window in each of the
training and test partitions.  Each request asks for three broadband
components through the \texttt{BH?} selector.  Event windows begin 900 seconds
after the USGS origin; quiet windows use the same clock time 24 hours earlier.
No waveform is redistributed in the submission package.

The parser handles segmented GeoCSV responses, chooses two horizontal
components and one vertical component, and interpolates them to the common
20-Hz time grid.  A request is rejected if coverage is below 95\% or any gap
exceeds one second.  The accepted requests supply either 4,799 or 4,800
common samples; the largest observed gap is approximately 0.05 seconds.  The source
records the URL, instrument string, units, sample rate, byte length, selected
channels, and SHA-256 digest for each request.  The 48 payloads total
29,029,069 bytes.

The preprocessing removes the mean from each 64-sample component window,
concatenates the three components, zero pads the 192 samples to $n=256$, and
normalizes each nonzero window to unit Euclidean norm.  No taper or
featurewise standardization is applied.  EarthScope
\texttt{scale=AUTO} supplies velocity units through the service-reported
scalar sensitivity.  This is not a claim of full poles-and-zeros response
deconvolution.

\section{Reproduction and falsification}

\begin{verbatim}
python -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install "./code[test]"
.venv/bin/python -m pytest code/tests
.venv/bin/taskbutterfly-reproduce --verify > reproduced.json
\end{verbatim}

The verifier rechecks every source digest and deterministic scientific
quantity.  It intentionally excludes wall-clock timing and BLAS-sensitive
measurements.  A candidate is rejected if any fixed task's simultaneous upper
bound exceeds 0.15; this occurs for all candidates in the registered replay.
The seismic endpoint does not support a
claim of operational event detection, phase picking, or superiority over
raw amplitude.
